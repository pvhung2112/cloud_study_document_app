CÁC ĐIỂM NGHẼN CỦA HẠ TẦNG TRUYỀN THỐNG (LOCAL/ON-PREMISE)

❌ 1. Không đồng bộ đa thiết bị

Tài liệu lưu trên máy tính không tự chuyển sang điện thoại thông minh khi sinh viên lên lớp.

❌ 2. Rủi ro mất trắng dữ liệu

Hỏng ổ cứng hoặc mất thiết bị đồng nghĩa mất toàn bộ ghi chú, đề cương và bài tập đã lưu.

❌ 3. Không thể cộng tác & chia sẻ

Không có đường dẫn link để chia sẻ bài giảng, bài tập nhóm cho bạn học trong cùng môn.

❌ 4. Tràn bộ nhớ máy khách

Lưu hàng trăm tệp Slide PDF và file Word chất lượng cao làm đầy bộ nhớ điện thoại cá nhân.

🎙️ Lời thoại thuyết trình: "Mô hình lưu trữ cục bộ bộc lộ 4 điểm nghẽn nghiêm trọng: không thể đồng bộ sang smartphone, rủi ro mất trắng dữ liệu khi hỏng máy, không thể chia sẻ tài liệu nhóm và làm đầy bộ nhớ thiết bị."
Checklist 3 • Lựa chọn nền tảng Trang 03

LỰA CHỌN NỀN TẢNG CLOUD: GOOGLE FIREBASE (BaaS)

🔐 Authentication

Đăng nhập Google Sign-In 1-chạm chuẩn OAuth 2.0. Không cần quản lý mật khẩu phức tạp.

📄 Cloud Firestore

Cơ sở dữ liệu NoSQL linh hoạt, hỗ trợ Real-time Streams lắng nghe thay đổi tự động.

📦 Cloud Storage

Lưu trữ tệp PDF, DOCX, ZIP an toàn trên hạ tầng Google Cloud Storage có CDN toàn cầu.

🏆 Tại sao chọn Firebase thay vì AWS hoặc Azure?

FlutterFire SDK là bộ công cụ chính chủ của Google, cài đặt cực nhanh qua CLI, gói Spark miễn phí trọn đời (1GB Firestore, 5GB Storage, 50k Reads/ngày) hoàn hảo cho sinh viên.

🎙️ Lời thoại thuyết trình: "Nhóm em lựa chọn Google Firebase vì đây là giải pháp Backend-as-a-Service tối ưu nhất cho Flutter, cung cấp sẵn Auth, Firestore và Storage mà không tốn bất kỳ chi phí nào cho đồ án sinh viên."

SO SÁNH MÔ HÌNH TRUYỀN THỐNG VS MÔ HÌNH CLOUD

Tiêu chí đánh giá Mô hình Truyền thống (Local SQLite) Mô hình Tích hợp Cloud (Firebase)
Phạm vi truy cập Chỉ trên 1 máy tính duy nhất Đa nền tảng: Web, Điện thoại, Laptop
Độ an toàn dữ liệu Dễ mất khi hỏng ổ cứng Sao lưu phân tán tự động trên Google Cloud
Xác thực tài khoản Không có / Lưu mật khẩu cục bộ Google Sign-In an toàn chuẩn OAuth 2.0
Lưu trữ tệp lớn Chiếm dung lượng ổ đĩa máy Lưu trên Cloud Bucket, tải theo nhu cầu
Tốc độ phản hồi Nhanh nhưng cô lập Cực nhanh (< 5ms) nhờ Local-First + Đồng bộ nền

Checklist 4 • Luồng dữ liệu Trang 06

LUỒNG DỮ LIỆU ĐỒNG BỘ TỆP TIN & METADATA

  • Bước 1: Người dùng tạo bài giảng hoặc bài tập, đính kèm file Slide.pdf ➔ Lưu vào Local DB (cờ isSynced = false) ➔ UI cập nhật tức thì.
  • Bước 2: Sync Engine quét thấy bản ghi chưa đồng bộ ➔ Đẩy tệp Slide.pdf lên Firebase Storage tại /study_docs/{uid}/Slide.pdf.
  • Bước 3: Firebase Storage trả về đường dẫn an toàn (Download URL).
  • Bước 4: Sync Engine ghi Metadata (tên môn, hạn nộp, Download URL) vào Cloud Firestore.
  • Bước 5: Nhận xác nhận thành công ➔ Đổi cờ thành isSynced = true tại máy khách.
🎙️ Lời thoại thuyết trình: "Luồng dữ liệu đảm bảo tính toàn vẹn 5 bước: lưu nhanh tại máy, tải file lên Storage, lấy URL lưu vào Firestore và cập nhật trạng thái đã đồng bộ thành công."
Checklist 6 • Kỹ thuật Auth Trang 07

TÍCH HỢP XÁC THỰC GOOGLE (GOOGLE SIGN-IN)

Sử dụng thư viện firebase_auth và google_sign_in trên Flutter:

// lib/struct/firebaseAuthService.dart final GoogleSignInAccount? googleUser = await GoogleSignIn().signIn(); final GoogleSignInAuthentication googleAuth = await googleUser!.authentication; final OAuthCredential credential = GoogleAuthProvider.credential( accessToken: googleAuth.accessToken, idToken: googleAuth.idToken, ); final UserCredential user = await FirebaseAuth.instance.signInWithCredential(credential); print('Đăng nhập thành công: ${user.user?.email}');

✔ Đăng nhập 1-chạm bằng Gmail • Không cần quản lý mật khẩu • Bảo mật an toàn với Token OAuth 2.0.

🎙️ Lời thoại thuyết trình: "Với Google Sign-In, sinh viên đăng nhập chỉ bằng một cú chạm. Hệ thống sử dụng token bảo mật OAuth 2.0 của Google nên loại bỏ hoàn toàn nguy cơ lộ mật khẩu."
Checklist 6 • Kỹ thuật Storage Trang 08

TÍCH HỢP LƯU TRỮ TỆP BÀI GIẢNG TRÊN CLOUD STORAGE

Sử dụng thư viện firebase_storage để tải tệp PDF/DOCX lên đám mây:

// lib/struct/firebaseCloudStorageService.dart final user = FirebaseAuth.instance.currentUser; final ref = FirebaseStorage.instance.ref().child('study_docs/${user!.uid}/$fileName'); // Tải file lên và theo dõi tiến trình final uploadTask = await ref.putFile(File(filePath)); // Lấy URL tải xuống vĩnh viễn final String downloadUrl = await uploadTask.ref.getDownloadURL();

✔ Tự động phân cấp thư mục theo UID người dùng • Tốc độ tải vượt trội nhờ Google Cloud CDN.

🎙️ Lời thoại thuyết trình: "Tệp bài giảng được lưu trên Cloud Storage theo từng mã UID của sinh viên. Đường dẫn tải về được sinh tự động và phân phối qua mạng CDN tốc độ cao của Google."

Checklist 7 • Setup tài khoản nhóm (Phần 1) Trang 10

HƯỚNG DẪN CẤU HÌNH TRÊN FIREBASE CONSOLE

  • Bước 1: Truy cập console.firebase.google.com bằng tài khoản Gmail của nhóm, bấm "Add project", đặt tên study-document-cloud.
  • Bước 2: Vào menu Authentication ➔ Sign-in method, chọn Google và bấm Enable.
  • Bước 3: Vào menu Cloud Storage ➔ Bấm Get Started, chọn máy chủ khu vực asia-southeast1 (Singapore).
  • Bước 4: Mời các thành viên trong nhóm: Vào Project Settings ➔ Users and permissions ➔ Add member để cả nhóm cùng quản trị.
🎙️ Lời thoại thuyết trình: "Để setup cho nhóm, trưởng nhóm tạo project trên Firebase Console, kích hoạt Auth Google, bật Cloud Storage và cấp quyền quản trị cho tất cả các thành viên trong nhóm."
Checklist 7 • Setup tài khoản nhóm (Phần 2) Trang 11

KẾT NỐI VÀO FLUTTER BẰNG FLUTTERFIRE CLI

Chỉ cần mở Terminal tại thư mục dự án và chạy các lệnh sau:

# 1. Cài đặt Firebase CLI toàn cục npm install -g firebase-tools # 2. Đăng nhập tài khoản Google của nhóm firebase login # 3. Kích hoạt công cụ FlutterFire CLI dart pub global activate flutterfire_cli # 4. Tự động liên kết mã nguồn Flutter với dự án Firebase flutterfire configure

➔ Lệnh trên tự động sinh tệp firebase_options.dart chứa đầy đủ API Key và cấu hình cho Web, Android, Windows!

🎙️ Lời thoại thuyết trình: "Tiếp theo, nhóm dùng FlutterFire CLI để kết nối tự động. Công cụ này sẽ tự tạo file firebase_options.dart chứa toàn bộ cấu hình mà không cần sửa code thủ công."
